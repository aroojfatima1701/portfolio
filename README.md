# Arooj Fatima · Portfolio

**Live site:** [aroojfatima-portfolio.netlify.app](https://aroojfatima-portfolio.netlify.app)

Full-stack developer who designs. This is the source of my portfolio website: a multi-page static site with live, embedded versions of my projects, case studies, brand identities and an animated hero.

- `index.html` · home, about, why work with me, contact
- `mega-projects.html` · Blinks (multi-vendor marketplace) and Saatio (SaaS)
- `websites.html` · live websites with desktop and phone previews
- `brand-identity.html` · Fanar, Crumb & Crema, Misk & Mirr, APX Athletics, Saatio, Regalia
- `live/` · the project websites themselves
- `case-studies/` · one case study per project

Plain HTML, CSS and JavaScript, no build step. Deploy the folder as is to Netlify, Vercel or GitHub Pages.
